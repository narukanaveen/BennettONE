# BennettONE — Centralized Bennett University Portal Hub

**Live Website:** https://narukanaveen.github.io/BennettONE/

BennettONE brings all everyday Bennett University student portals, campus map, mess menu, and quick utilities together on a single dark-themed responsive webpage.

## Portals Included
- **Campus Map** — Bennett University Greater Noida layout
- **Bennett LMS** — Course notes, lab manuals, and assignment uploads
- **MyCAMU Portal** — Live attendance, class timetable, and exam results
- **Bennett E-Library** — Digital textbooks, IEEE journals, and past papers
- **Bennett Official Website** — Circulars, academic calendar, and campus updates
- **BU Mess Menu** — Daily breakfast, lunch, snacks, and dinner menu
- **Placement Portal** — On-campus placement drives and internships
- **Outlook Student Mail** — Official `@bennett.edu.in` inbox and viva bookings
- **Quick Utilities (4-Block Grid)** — `r/BennettUniversityGN`, Bennett LinkedIn, Campus Wi-Fi Passwords guide, and 9.4 SGPA Calculator
